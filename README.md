Análisis Exploratorio de Datos: Riesgo Crediticio en Chile

Instrucciones de Revisión

Opción 1: Revisión Web (Recomendada)
Puede visualizar el código, los gráficos y el análisis directamente haciendo clic en el archivo "proyecto semana 3.ipynb" en este repositorio de GitHub.

Opción 2: Ejecución Local

Paso 1: Clonar el repositorio en su terminal: git clone https://github.com/RGVenegas/Proyecto-Ciencia-datos.git

Paso 2: Instalar las dependencias requeridas (requiere Python): pip install pandas numpy matplotlib seaborn

Paso 3: Abrir "proyecto semana 3 predictivo.ipynb" (en Jupyter Notebook o VS Code) y ejecutar todas las celdas de forma secuencial.
